CAN & Ethernet Intrusion Detection System

Cybersecurity + Edge ML + Multi-Protocol Vehicle Networking

Multi-protocol IDS covering CAN, DoIP, and SOME/IP with ML-based anomaly detection. Two-stage pipeline: unsupervised anomaly detection using autoencoder and Isolation Forest trained on normal traffic patterns, then supervised classification to identify attack types (DoS, fuzzing, spoofing). Multi-scale temporal feature extraction at 10ms, 100ms, and 500ms windows catches both fast flooding attacks and slow stealthy manipulation. Edge deployed via TFLite Micro on QEMU Cortex-M7 emulator with documented flash, RAM, and latency benchmarks showing the accuracy-resource tradeoff between float32 and INT8 quantized models. Every detection is explainable through SHAP — which protocol feature triggered the alert and why.

Predictive Vehicle Health & Prognostics Platform

Sensor Telemetry + Diagnostic Intelligence + Fleet Prognostics for Autonomous Vehicles

Fleet-level predictive diagnostics that combines traditional UDS diagnostic data with continuous sensor health telemetry across 17 parameters — camera frame rate and blur, LiDAR point density and calibration drift, radar noise floor, IMU bias drift, compute inference latency, and network packet loss. Streaming ingestion via MQTT into TimescaleDB with data validation. XGBoost predicts component failure within 30 days, while Cox Proportional Hazard survival analysis estimates remaining useful life with confidence intervals. Cross-sensor correlation detects shared root causes — camera and LiDAR degrading simultaneously suggests power or compute issues, not independent sensor faults. An operational decision engine maps predictions to fleet actions: restrict to low-speed routes, schedule calibration, or pull from service. UDS diagnostic server over DoIP lets standard service tools query AI-generated health predictions through established automotive protocols.

Autonomous Fleet OTA Intelligence Platform

Predictive Risk Scoring + Staged Rollout + Dependency-Aware Rollback

ML-based OTA campaign intelligence for autonomous vehicle and robotics fleets. An eligibility engine checks seven pre-conditions before any vehicle can update — parked state, battery SOC thresholds that vary per ECU, connectivity type matched to package size, and firmware version compatibility critical for delta updates. XGBoost risk scoring predicts update failure probability per vehicle using twelve features including ECU hardware revision history, connectivity stability, and delta vs full image risk. A seven-ECU dependency graph with topological ordering ensures gateway updates before perception, perception before planning. Staged rollout promotes from 1% canary through 10%, 50%, to full fleet with configurable failure rate thresholds and soak times. The rollback engine is dependency-aware — when ECU C fails mid-update, it checks the compatibility matrix to determine if already-updated ECUs A and B can coexist with C's old version, or if cascade rollback is needed. Before executing any rollback, an ML model predicts rollback success probability per ECU. All nine real-world failure modes are simulated — from download timeouts to battery death mid-flash. A/B cohort comparison with statistical significance testing validates post-rollout improvement. Every decision is audit-logged for regulatory compliance.

Autonomous Vehicle Real-Time Safety Monitor

On-Vehicle AD Stack Health Monitoring + ISO 26262 Safety Response + UDS/DoIP Diagnostics

Real-time on-vehicle safety monitor for an autonomous driving stack built on ROS2. Five sensor health monitors run at 10Hz tracking camera frame rate and blur, LiDAR point density and calibration drift, radar detection consistency, compute inference latency, and network message integrity. A diagnostic aggregator uses rolling z-score anomaly detection — not heavy ML, because this runs on-vehicle with a 5ms latency budget. Cross-sensor correlation distinguishes shared root causes from isolated faults — camera and LiDAR degrading simultaneously triggers an ASIL D response because it suggests power failure, not independent sensor issues. The safety response engine maps health scores to ISO 26262 aligned degradation levels with hysteresis to prevent oscillation: nominal operation, reduced operational design domain, minimal risk condition, or immediate safe stop. A UDS diagnostic server over DoIP exposes AD-specific DTCs and health data through standard automotive protocols — the same interface every service center uses. SOME/IP health reporting lets other vehicle ECUs subscribe to AD health status. Fleet telemetry uplink streams events via MQTT in a schema compatible with the Predictive Diagnostics platform. Validated across six degradation scenarios with measured detection latency, false positive rates, and response times.
