01 Complete
Cybersecurity + Edge ML + Multi-Protocol Vehicle Networking

CAN & Ethernet Intrusion Detection System

Multi-protocol IDS covering CAN, DoIP, and SOME/IP with ML-based anomaly detection. Two-stage pipeline: unsupervised anomaly detection using autoencoder and Isolation Forest trained on normal traffic patterns, then supervised classification to identify attack types (DoS, fuzzing, spoofing). Multi-scale temporal feature extraction at 10ms, 100ms, and 500ms windows catches both fast flooding attacks and slow stealthy manipulation. Edge deployed via TFLite Micro on QEMU Cortex-M7 emulator with documented flash, RAM, and latency benchmarks. Every detection is explainable through SHAP — which protocol feature triggered the alert and why.

02 Complete
Sensor Telemetry + Diagnostic Intelligence + Fleet Prognostics

Predictive Vehicle Health & Prognostics Platform

Fleet-level predictive diagnostics combining traditional UDS diagnostic data with continuous sensor health telemetry across 17 parameters — camera frame rate and blur, LiDAR point density and calibration drift, radar noise floor, IMU bias drift, compute inference latency, and network packet loss. Streaming ingestion via MQTT into TimescaleDB with data validation. XGBoost predicts component failure within 30 days; Cox Proportional Hazard survival analysis estimates remaining useful life with confidence intervals. Cross-sensor correlation detects shared root causes. A UDS diagnostic server over DoIP exposes AI-generated health predictions through standard automotive protocols.

03 In Progress
Predictive Risk Scoring + Staged Rollout + Dependency-Aware Rollback

Autonomous Fleet OTA Intelligence Platform

ML-based OTA campaign intelligence for autonomous vehicle and robotics fleets. An eligibility engine checks seven pre-conditions before any vehicle can update — parked state, battery SOC thresholds, connectivity type, and firmware version compatibility. XGBoost risk scoring predicts update failure probability per vehicle using twelve features. A seven-ECU dependency graph with topological ordering ensures gateway updates before perception, perception before planning. Staged rollout promotes from 1% canary through 10%, 50%, to full fleet. The rollback engine is dependency-aware — checking the compatibility matrix before cascade rollback. All nine real-world failure modes simulated, with A/B cohort comparison and audit logging for regulatory compliance.

04 In Progress
On-Vehicle AD Stack Health Monitoring + ISO 26262 Safety Response

Autonomous Vehicle Real-Time Safety Monitor

Real-time on-vehicle safety monitor for an autonomous driving stack built on ROS2. Five sensor health monitors run at 10Hz tracking camera, LiDAR, radar, compute latency, and network integrity. A diagnostic aggregator uses rolling z-score anomaly detection with a 5ms latency budget. Cross-sensor correlation distinguishes shared root causes from isolated faults. The safety response engine maps health scores to ISO 26262-aligned degradation levels with hysteresis: nominal, reduced ODD, minimal risk condition, or immediate safe stop. A UDS diagnostic server over DoIP exposes AD-specific DTCs. Validated across six degradation scenarios with measured detection latency, false positive rates, and response times.
