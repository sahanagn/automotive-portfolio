PROJECT 01
COMPLETE

CAN & Ethernet Intrusion Detection System

Cybersecurity + Edge ML + Multi-Protocol Vehicle Networking

Multi-protocol IDS covering CAN, DoIP, and SOME/IP with ML-based anomaly detection. Two-stage pipeline: unsupervised anomaly detection (autoencoder + Isolation Forest) then supervised attack classification. Multi-scale temporal features at 10ms/100ms/500ms windows. Edge deployed via TFLite Micro on QEMU Cortex-M7 with documented flash/RAM/latency benchmarks. Every detection explainable via SHAP.

SocketCAN DoIP SOME/IP (vsomeip) PyTorch scikit-learn TFLite Micro QEMU ARM SHAP MLflow Grafana Docker
Target roles: Vehicle Cybersecurity Engineer, IDS/IPS Engineer, Embedded ML Engineer

PROJECT 02
COMPLETE

Predictive Vehicle Health & Prognostics Platform

Sensor Telemetry + Diagnostic Intelligence + Fleet Prognostics for Autonomous Vehicles

Fleet-level predictive diagnostics combining UDS diagnostic data with 17-parameter sensor health telemetry (camera, LiDAR, radar, IMU, compute, network). Streaming ingestion via MQTT into TimescaleDB. XGBoost failure prediction + Cox Proportional Hazard survival analysis for remaining useful life estimation. Operational decision engine mapping predictions to fleet actions. UDS/DoIP diagnostic interface with standard automotive protocols.

python-udsoncan DoIP SOME/IP MQTT TimescaleDB XGBoost lifelines SHAP FastAPI Streamlit MLflow Docker
Target roles: Vehicle Health Engineer, Fleet Analytics, Predictive Maintenance, Prognostics & Health Management

PROJECT 03
IN PROGRESS

Autonomous Fleet OTA Intelligence Platform

Predictive Risk Scoring + Staged Rollout + Dependency-Aware Rollback

ML-based OTA campaign management for autonomous fleets. Eligibility engine with 7 pre-conditions. XGBoost risk scoring per vehicle. Delta vs full image risk-aware selection. 7-ECU dependency graph with topological update ordering. Staged rollout (1%→10%→50%→100%) with automated gate logic. Dependency-aware rollback with ML-predicted rollback success probability. All 9 real-world failure modes simulated. A/B cohort comparison with statistical significance testing. Full audit trail.

UPTANE MQTT NetworkX XGBoost SciPy SHAP FastAPI Streamlit PostgreSQL MLflow Docker
Target roles: OTA Platform Engineer, Fleet Infrastructure, Vehicle Software Integration, Release Engineering

PROJECT 04
IN PROGRESS

Autonomous Vehicle Real-Time Safety Monitor

On-Vehicle AD Stack Health Monitoring + ISO 26262 Safety Response + UDS/DoIP Diagnostics

Real-time on-vehicle safety monitor for autonomous driving stacks using ROS2. Monitors camera, LiDAR, radar, compute, and network health at 10Hz. Rolling z-score anomaly detection with cross-sensor correlation. ISO 26262 aligned safety response engine with ASIL-rated monitors, FMEA table, and hysteresis. UDS/DoIP diagnostic server exposing AD health through standard automotive protocols. SOME/IP health reporting to vehicle gateway. Fleet telemetry uplink compatible with Project 02.

ROS2 python-udsoncan DoIP SOME/IP ISO 26262 OpenCV Open3D MQTT nuScenes Docker
